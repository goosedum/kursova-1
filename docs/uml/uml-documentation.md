# Документація до UML-діаграм

Діаграми написані текстом у PlantUML (`.puml`), поруч із кожною лежить готова картинка `.png` (200 dpi, чорно-біла).

## 1. Прецеденти — `1-use-cases/`

| Файл | Що показує |
|---|---|
| `1-overview` | Користувач і всі 17 прецедентів, які він викликає (Файли, Вакансії, Аналіз, Довідка) |
| `2-files` | Робота з файлами: відкрити, зберегти, новий каталог, перевірки й попередження |
| `3-vacancies` | Робота з вакансіями: переглянути, додати, редагувати, дублювати, видалити |
| `4-analysis-and-help` | Функції аналізу 1–6 і довідка |

## 2. Класи — `2-classes/`

| Файл | Що показує |
|---|---|
| `1-overview` | Усі класи без полів і зв'язки між шарами ViewModel → Logic → Model / Storage |
| `2-model-and-files` | Модель даних (`Vacancy`, переліки, `VacancyError`) і читання/запис файлу (`>>`, `<<`) |
| `3-functions-1-6` | Функції 1–6: базовий клас `CatalogOperation`, 6 підкласів, сортування злиттям `MergeSorter<Element>` |
| `4-viewmodel-and-catalog` | Стан вікна `CatalogViewModel` і каталог вакансій `VacancyCatalog` |

`types/` — опис кожного класу (поля, методи) один раз для всіх діаграм класів; діаграми підключають його через `!include`.
Діаграми класів звірено з кодом 27.10.2026 (крок 4.15): 21 тип, усі поля й методи збігаються (Views і DesignSystem — шар інтерфейсу SwiftUI, на діаграми класів не виносимо).

## 3. Послідовності — `3-sequences/`

| Файл | Що показує |
|---|---|
| `1-open-file` | Відкриття файлу: читання рядків оператором `>>`, конструктор копій, зупинка на помилковому рядку (каталог не змінюється) |
| `2-merge-sort` | Ф.4: поліморфний виклик `execute(on:)`, рекурсивне сортування злиттям, результат у таблиці |
| `3-add-vacancy` | Додавання вакансії: форма з `Vacancy()`, перевірка `validate()`, виняток `VacancyError` → алерт |

`style.iuml` — спільний стиль діаграм послідовності.

## 4. Діяльність — `4-activities/`

| Файл | Що показує |
|---|---|
| `1-sort` | Рекурсивне сортування злиттям `sort(_:by:)`: ≤ 1 елемента — повернути, інакше поділити навпіл, відсортувати половини, злити |
| `2-merge` | Злиття двох відсортованих половин `merge(_:_:by:)`; при рівності першим іде елемент лівої половини (стабільність) |

`style.iuml` — спільний стиль діаграм діяльності.

## Як перемалювати картинки

```bash
cd ~/kursova-1/docs/uml && plantuml -tpng 1-use-cases/*.puml 2-classes/*.puml 3-sequences/*.puml 4-activities/*.puml
```
