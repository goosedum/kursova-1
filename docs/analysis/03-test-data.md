## 1. Файли

| Файл | Призначення | Очікуваний результат відкриття |
|---|---|---|
| `vacancies.txt` | основний демо-каталог | 28 вакансій, без помилок |
| `broken-field-count.txt` | виняток «неправильна кількість полів» | «Рядок 5: очікувалось 8 полів, знайдено 7» |
| `broken-salary.txt` | виняток «зарплата не є числом» | «Рядок 6: … "abc" не є числом» |
| `broken-level.txt` | виняток «невідомий рівень досвіду» | «Рядок 7: невідомий рівень досвіду "Pro"» |
| `broken-min-max.txt` | виняток «мін. більша за макс.» (з файлу) | «Рядок 4: мінімальна зарплата (5000) більша за максимальну (3000)» |
| `empty.txt` | порожній файл | без помилки → порожній каталог (порожній стан з порадами) |

У зламаних файлах решта рядків коректні, а перший рядок-коментар пояснює, що саме зламано.
Номери рядків рахуються як у текстовому редакторі (разом із коментарями): у `vacancies.txt` вакансія № N стоїть у рядку N + 2.
