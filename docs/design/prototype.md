# Клікабельний прототип (крок 2.7)

Сторінка Figma **07 Prototype**. Як дивитися: відкрити сторінку → **▶ Present** (Shift+Space) → праворуч угорі вибрати потік.
Якщо клікнути повз, Figma підсвітить клікабельні місця.

- Потік П-1: <https://www.figma.com/proto/YDr0praKAGRczdbVic7XzA?node-id=83-2&starting-point-node-id=83%3A2>
- Потоки П-2 і П-3 (починаються з одного екрана): <https://www.figma.com/proto/YDr0praKAGRczdbVic7XzA?node-id=83-624&starting-point-node-id=83%3A624>

Екрани прототипу — копії екранів зі сторінки 06 Screens (номер у дужках) і три додаткові стани (P-09b, P-12b, P-10b).

## П-1. Відкрити файл → функція 4

| Екран | Клік | Перехід |
|---|---|---|
| P-01 Порожній каталог (S-01) | «Відкрити файл…» або 📂 на панелі | P-02 |
| P-02 Усі вакансії (S-02) | «Сортування за ЗП» у сайдбарі | P-06 |
| P-06 Ф.4 Сортування (S-06) | «Усі вакансії» | P-02 |

## П-2. Додати вакансію: помилка → виправлення

| Екран | Клік | Перехід |
|---|---|---|
| P-02 Усі вакансії | «+» на панелі | P-09 |
| P-09 Нова вакансія, порожня (S-09) | по полях («ввести дані») / «Скасувати» | P-11 / P-02 |
| P-11 Форма з помилками (S-11) | «Зберегти» / по полях («виправити») / «Скасувати» | P-16 / P-09b / P-02 |
| P-16 Алерт «Неправильний діапазон зарплати» (S-16) | «OK» | P-11 |
| P-09b Нова вакансія, заповнена правильно | «Зберегти» / «Скасувати» | P-02 |

«Зберегти» завжди активна: `validate()` кидає `VacancyError`, форма ловить виняток і показує алерт (D-31).

## П-3. Контекстне меню → дублювати / видалити

| Екран | Клік | Перехід |
|---|---|---|
| P-02 Усі вакансії | рядок PixelSoft «Senior Frontend Developer» (у прототипі клік = ПКМ) | P-12 |
| P-12 Контекстне меню (S-12) | «Дублювати» / «Видалити» | P-12b / P-18 |
| P-12b Копія вставлена під оригіналом і виділена, «● Є незбережені зміни», 29 вакансій | ✎ «Редагувати» на панелі | P-10b |
| P-10b Редагування копії | «Зберегти» / «Скасувати» | P-12b |
| P-18 Підтвердження видалення (S-18.1) | «Видалити» / «Скасувати» | P-02 |

«Дублювати» одразу вставляє копію під оригіналом і виділяє її, без форми (UC-09). Редагувати копію можна далі (UC-08).

## Спрощення прототипу

- Клік по рядку замінює правий клік (Figma не має тригера ПКМ).
- Після «Зберегти» у формі нової вакансії прототип повертається до таблиці без нового рядка: у програмі вакансія додається
  в кінець каталогу й виділяється (UC-07).
